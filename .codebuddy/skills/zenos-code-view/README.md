# zenos-code-view

一个 CodeBuddy Code skill：给已有代码补充清晰、有价值的中文注释，让阅读者快速理解「这段程序在做什么、为什么这么做」。

## 能做什么

- 为文件 / 函数 / 类 / 选中代码块添加注释与逐段解读
- 生成文档注释：Python docstring、JSDoc、Javadoc、Go doc comment 等
- 梳理复杂算法、位运算、正则、状态机、魔法数字、隐式业务约定
- 解释「为什么这么写」，而不只是复述代码

**核心约束：只新增注释，不改动任何原有逻辑、变量名、控制流与格式。**

## 安装

技能目录放到 CodeBuddy Code 的 skills 目录下即可：

```bash
unzip zenos-code-view.zip -d ~/.codebuddy/skills/
```

目录结构：

```
zenos-code-view/
├── SKILL.md     # 技能定义（frontmatter + 注释规则与工作流）
└── README.md    # 本文件
```

安装后重启 / 刷新会话以加载新技能。

## 使用

- 显式调用：`/zenos-code-view`
- 或直接说：给这段代码加注释、注释一下、解释这段代码、生成文档注释、`/annotate code`、`document this function` 等

技能命中后会自动：确认注释范围 → 通读代码与上下文 → 识别值得注释的位置 → 用 Edit 写回注释 → 复核零逻辑改动。

## 注释原则速览

| 原则 | 说明 |
|---|---|
| 解释「为什么」优先 | 说明意图、约束、业务背景、边界条件，不写 `i++ // i 加 1` |
| 只注释不明显处 | 复杂逻辑、易踩的坑、与直觉相悖的写法 |
| 公开接口补文档注释 | 用途、参数、返回值、异常、性能约束 |
| 中文、准确、克制 | 注释与代码一致，不臆造，不逐行翻译 |
| 沿用既有风格 | 文件已有 JSDoc 就用 JSDoc，已有 `#` 就用 `#` |

完整规则、各语言注释语法表与示例见 `SKILL.md`。

## 不适用

重构、修 bug、改实现、加功能、删除代码、或把代码「注释掉（禁用）」——这些按普通编码任务处理，不要用本技能。
